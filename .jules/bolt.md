## 2024-10-16 - Vite Dynamic Import Chunking Optimization

**Learning:** When trying to separate heavy dependencies like `jspdf` and `html2canvas` into a separate chunk to avoid blocking the main bundle load, directly wrapping them in an exported function and using `await import(...)` inside that function does not separate the dependencies if the function itself is statically imported in a main path (like `main.js` importing `matrix-view.js` which imports the function). Vite will not pull it into a new chunk if there's any static import dependency chain leading to it.

**Action:** To correctly separate it, you must move the function containing the heavy imports into its own dedicated file (e.g., `pdf-export.js`). Then, the component that needs it (e.g., `matrix-view.js`) must only import that file *dynamically* inside the event handler that requires it (e.g., `await import('./pdf-export.js')`), ensuring no static `import { ... } from './pdf-export.js'` exists at the top level. Additionally, modifying `build.rolldownOptions.output.manualChunks` in `vite.config.js` allows explicit separation of vendor libraries into a `pdf-vendor` chunk for maximum predictability.
